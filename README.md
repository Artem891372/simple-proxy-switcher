# Simple Proxy Switcher

Простое расширение для Chrome (Manifest V3) для переключения прокси с поддержкой белого и чёрного списков сайтов.

## Возможности

- Настройка HTTP/SOCKS-прокси (хост, порт, логин, пароль)
- Включение/выключение прокси одним кликом
- **Белый список** — прокси используется только для указанных сайтов
- **Чёрный список** — прокси не используется для указанных сайтов
- Автоматическая авторизация на прокси (onAuthRequired)
- Настройки синхронизируются через `chrome.storage.sync`

## Установка

1. Скачайте или склонируйте репозиторий
2. Откройте `chrome://extensions`
3. Включите «Режим разработчика»
4. Нажмите «Загрузить распакованное расширение» и выберите папку проекта

## Использование

1. Кликните по иконке расширения на панели
2. Задайте хост, порт и при необходимости логин/пароль прокси
3. Переключите тумблер для включения прокси
4. На странице настроек настройте белый/чёрный списки доменов

## Структура

- `background.js` — service worker: управление прокси, авторизация, фильтрация по спискам
- `popup.html` / `popup.js` — быстрое переключение и базовые настройки
- `options.html` / `options.js` — расширенные настройки (списки доменов)
- `rules.json` — правила declarativeNetRequest
- `bypass.html` — страница-заглушка для заблокированных адресов
- `manifest.json` — манифест расширения (MV3)

## Примечания

- Требуется Chrome/Chromium с поддержкой Manifest V3 и permission `proxy`
